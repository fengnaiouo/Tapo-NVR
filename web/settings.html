攝影機

掃描結果

      攝影機帳密請在 Tapo App → 攝影機 → 設定 → 進階設定 →「攝影機帳戶」建立，並到「我 → 第三方服務」開啟「第三方相容性」。

      錄影

      每台攝影機的錄影模式（連續 / 只錄移動事件 / 關閉）請到「攝影機」→ 編輯設定。磁碟剩餘空間低於 2 GB 時會自動刪除最舊的錄影。

      偵測與通知

      監控首頁右上角的「🛡 布防 / 撤防」按鈕也可以快速切換。

      🕒 通知時段

      結束時間早於開始時間代表跨夜，例如 22:00–07:00。時段外仍會記錄事件與錄影，只是不推送通知。

      ⚙ 偵測

      要開關個別攝影機的移動偵測或通知，請到「攝影機」→ 編輯。

      📱 手機推播（ntfy，免費）

      1. 手機安裝 ntfy App（iOS / Android）
      2. 在下方取一個不易被猜到的主題名稱，例如 tapo-xxxx
      3. 在 App 中訂閱同一個主題，按「傳送測試」確認

      帳號安全

      變更密碼後，其他已登入的瀏覽器與桌面版都會被登出。

      伺服器與外網

      開啟後信任 Cloudflare 傳來的真實 IP 與 HTTPS 標頭（登入次數限制、安全 Cookie）。
      進階：內部連接埠
      只綁定在本機（127.0.0.1），不需要開放防火牆。與其他程式衝突時才需要修改，儲存後立即套用。

      Cloudflare Tunnel 設定步驟

      1. 安裝：winget install Cloudflare.cloudflared
      2. cloudflared tunnel login → cloudflared tunnel create tapo-nvr
      3. cloudflared tunnel route dns tapo-nvr cam.你的網域.com
      4. 設定轉送到 http://localhost:8080，並勾選上方「透過 Cloudflare Tunnel 對外」
      5. 詳見專案內 docs/cloudflare-tunnel.md

      此裝置

      以下設定只存在這個瀏覽器 / 這台電腦。

      桌面版設定

      開機自動啟動、桌面通知開關、變更伺服器：請在系統匣圖示按右鍵設定。
