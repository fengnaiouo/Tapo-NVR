# Tapo NVR

[English](README.md) | [繁體中文](README_TW.md) | [简体中文](README_CN.md) | **日本語** | [한국어](README_KO.md)

Rust で開発された、TP-Link Tapo カメラ向けの無料・オープンソースの監視・録画システムです。**Windows デスクトップアプリ**（サーバー内蔵）と **Web 版**があり、どちらも同じ機能を備えています。UI は英語・繁体字中国語・簡体字中国語に対応しています（システム言語から自動選択）。

🌐 Web サイト：<https://fengnaiouo.github.io/Tapo-NVR/> · ⬇️ [最新版をダウンロード](https://github.com/fengnaiouo/Tapo-NVR/releases/latest)

## 機能

| 分類 | 内容 |
|---|---|
| ライブ映像 | 複数カメラのグリッド表示、2K メインストリーム、LAN では低遅延 WebRTC、インターネット経由では MSE、1〜4 倍のデジタルズーム |
| パン・チルト | 押し続けて連続移動、キーボードの矢印キー、プリセットの追加／移動／削除（ONVIF または Tapo API） |
| カメラ制御 | プライバシーモード、ナイトビジョン、動体検知と感度、人物検知、自動追尾、SD カードの状態 |
| 録画 | カメラごとに**常時録画**または**動体検知時のみ録画**（前後の映像を含む）を選択、保存日数と容量の上限、ディスク残量が少ないときの自動削除 |
| 再生 | 24 時間タイムライン（15 分まで拡大可能）、イベントマーカー、0.5〜16 倍速、スナップショット、**MP4 書き出し** |
| 通知 | 動体検知、スナップショット、イベント履歴；Windows ネイティブ通知、ブラウザー通知、**スマートフォンへのプッシュ通知**（ntfy）；ワンクリックで**警戒 / 解除**、**通知時間帯**（夜間のみなど）、**カメラのオフライン / 復帰**通知 |
| 双方向音声 | PC からカメラに向かって話せます（TP-Link アカウントのパスワードが必要） |
| 対応機種 | LAN 自動検出（ONVIF + TP-Link TDP）、C1xx / C2xx / C3xx / C5xx などの Tapo 機種に対応；RTSP 非対応の機種は Tapo 独自ストリームを使用；旧方式と新方式（TPAP）のログインに対応 |
| リモート視聴 | LAN 内で直接接続、または Cloudflare Tunnel 経由で外出先から接続 |
| 設定 | **すべての設定はアプリまたは Web の ⚙ 設定画面で変更可能**、ほとんどの変更は即時反映；設定のバックアップと復元（パスワードを除く）、システムログの表示、「更新と情報」でバージョンと更新状況を確認 |
| デスクトップ版 | タスクトレイ常駐、Windows 起動時に自動起動、ウィンドウを閉じてもバックグラウンドで録画を継続、アプリ内自動アップデート |
| セキュリティ | 設定は SQLite に保存し、**カメラのパスワードは Windows DPAPI で暗号化**；パスワードは設定ファイルやプロセスのコマンドラインに現れません；セッションはハッシュのみ保存し、**ブラウザー / アプリを閉じるか再起動すると再ログインが必要**；Argon2、ログイン試行回数の制限、CSRF 対策；カメラのパスワードはブラウザーに送信されません |

## 使い方

### 1. カメラの準備（Tapo アプリ）

1. カメラ → ⚙ 設定 → **高度な設定 → カメラのアカウント**：RTSP/ONVIF 用のユーザー名とパスワードを作成
2. **ホーム → サードパーティサービス → サードパーティ互換性**：オンにする
3. ルーターでカメラに**固定 IP** を割り当てる

### 2a. デスクトップアプリ（推奨）

1. [Releases](https://github.com/fengnaiouo/Tapo-NVR/releases/latest) から `Tapo-NVR_x.y.z_x64-setup.exe` をダウンロードして実行
2. 初回起動時に管理者アカウントを作成
3. **⚙ 設定 → カメラ**：**LAN をスキャン** → **追加** → カメラのアカウントを入力 → **接続テスト** → 保存
4. **⚙ 設定 → 録画**：録画フォルダーを選択（容量の大きいドライブを推奨）し、カメラごとに録画モードを選択
5. （任意）TP-Link アカウントのパスワードを入力すると、プライバシーモード、ナイトビジョン、双方向音声などの制御が使えます。必要なのはパスワードだけで、カメラのローカルログインユーザーは常に `admin` です

- データはインストールフォルダー（例：`D:\Tapo NVR\`）に保存されます：`data\`（設定データベース・イベント・スナップショット）、`logs\`、`webview\`。録画は選択したフォルダーに保存。更新してもデータは残り、アンインストール時に「アプリケーションデータを削除」を選んだ場合のみ削除されます
- インストールフォルダーに書き込めない場合（`C:\Program Files` など）は `%APPDATA%\com.tapo-nvr.desktop\` を使用します
- 0.2.x からのアップグレード時は、古い `config.toml` が自動的に取り込まれ、ファイル内のパスワードは削除されます
- **アプリの環境設定**で**別の PC に接続**モードに切り替えると、視聴専用として使えます

### 2b. スタンドアロンサーバー

```powershell
.\scripts\setup.bat     # go2rtc / ffmpeg のダウンロードとビルド
.\scripts\start.bat     # 起動後、http://localhost:8080 を開く
```

### 他の端末から視聴する

同じ LAN 内のスマートフォンや PC のブラウザーで `http://<Tapo NVR を実行している PC の IP>:8080` を開きます。

**Windows ファイアウォール**（プライベートネットワークのみ許可）：

```powershell
New-NetFirewallRule -DisplayName "Tapo NVR Web" -Direction Inbound -Protocol TCP -LocalPort 8080 -Profile Private -Action Allow
New-NetFirewallRule -DisplayName "Tapo NVR WebRTC" -Direction Inbound -Protocol UDP -LocalPort 8555 -Profile Private -Action Allow
New-NetFirewallRule -DisplayName "Tapo NVR WebRTC TCP" -Direction Inbound -Protocol TCP -LocalPort 8555 -Profile Private -Action Allow
```

外出先からの視聴は [docs/cloudflare-tunnel.md](docs/cloudflare-tunnel.md)（繁体字中国語）を参照してください。

## アップデート

デスクトップ版は起動 30 秒後と 6 時間ごとに新しいバージョンを確認します。新バージョンがあると、アプリのウィンドウ右下に更新内容を含むカードが表示されます。**今すぐ更新**を押すと進捗バー付きでダウンロードし、自動的にインストールして再起動します。タスクトレイのメニュー →**アップデートを確認**から手動で確認することもできます。

## 録画について

- ファイル：`{録画フォルダー}\{カメラ ID}\{日付}\{時-分-秒}.mp4`、一般的な動画プレーヤーで再生できます
- 録画中のセグメントは `.rec.mp4`（クラッシュしても破損しません）で、完了後に通常の `.mp4` に変換されます
- **動体検知録画**は常時録画を行い、動きのないセグメントを自動削除するため、イベント前の映像も残ります
- 2K の常時録画は 1 台あたり 1 日約 15〜25 GB を使用します

## 注意事項

- **双方向音声**には TP-Link アカウントのパスワードが必要で、ローカル、デスクトップ版、または HTTPS 環境で使用できます。Cloudflare Tunnel 経由では使用できません
- **ロック防止**：Tapo カメラはパスワードを何度も間違えるとロックされるため、パスワードが間違っている場合は再試行を停止します
- 本プロジェクトは TP-Link とは関係ありません。Tapo は TP-Link の商標です
